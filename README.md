# MoneyLab · 데이터 수집과 전략 연구 포트폴리오

## 어떤 문제를 해결했나요?

- **수집량만 보이고 내용을 확인하기 어려움:** 종목별 관측 타임라인과 구간별 가격 그래프를 제공하고, 실제 관측 공백을 표시합니다.
- **동일 파일 확인과 반복 조회가 느림:** 검증 기록, 날짜별 색인, 입력·설정·코드 버전이 일치하는 결과를 재사용합니다.
- **다수 전략 비교에 오래 걸림:** 공통 계산을 재사용하고 GPU 일괄 계산과 CPU 기준 결과를 대조합니다.
- **계산이 중단됐는지 알기 어려움:** 단계·완료량·최근 갱신·중단 이유를 표시하고 체크포인트로 이어서 실행합니다.
- **가상 성과를 실제 성과로 오해할 위험:** 관측 사실과 체결 가정, 탐색과 독립 검증을 구분합니다.

## 측정 결과를 어떻게 해석하나요?

| 사례 | 개발 기록의 결과 | 반드시 함께 볼 조건 |
|---|---|---|
| GPU 모의운용 계산 | CPU 8.319초 → GPU 0.757초, 약 11배 | 실제 수신 사건 6,000건·4,020개 봇·RTX 5080. 초기화·저장·통신을 제외한 계산 구간 |
| 파일 증분 확인 | 최초 1.015초 → 반복 0.094초 | 격리된 로컬 시험 파일 600개. 실제 네트워크 전송 성능 아님 |
| 작은 리플레이 묶음 | CPU 1.0423초, GPU 혼합 2.0350초 | 합성 시험 입력 32,400행·16설정, 초기화·전송·저장 포함. 이 조건에서는 GPU가 느려 CPU를 기본으로 사용 |

이 수치는 개발 기록을 정리한 것이며 이번 공개 과정에서 원본 시장 자료로 재측정하지 않았습니다. 상이한 입력·측정 범위의 결과를 서로 비교하지 않습니다. [측정 근거와 한계](docs/evidence.md)를 함께 확인해 주세요.
