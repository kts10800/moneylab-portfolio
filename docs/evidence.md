# 측정 근거와 해석 범위

아래 수치는 2026-09-30에 확인한 MoneyLab 개발 문서의 기록입니다. 공개 저장소를 만들면서 시장 원본을 재실행하거나 다시 측정하지 않았습니다. 원본 시장 자료와 전체 실행 환경을 공개하지 않아 외부에서 동일 수치를 재현할 수 있는 벤치마크 묶음은 아닙니다.

## 실시간 모의운용 계산 비교

- 기록일: 2026-09-17
- 입력: 보관된 실제 체결·호가 사건 6,000건, 동일한 4,020개 봇, 32건 단위 순차 공급
- 장비: GPU NVIDIA RTX 5080, CPU 16개 작업자
- 결과: CPU 8.319초, GPU 0.757초, 비율 약 11.0배
- 포함: 해당 입력의 계산 처리
- 제외: 초기화·시작 준비·최종 파일 저장·정기 보고 및 실제 수신 네트워크 지연
- 문서에 기록된 검증: CPU/GPU 결과·거래·주문 사건·자산곡선 비교
- 원문 위치: 개발 저장소 `docs/gpu-live-engine.md`

이 결과는 실제 주문 속도, 전체 프로그램 속도, 전략 수익률을 뜻하지 않습니다.

## 작은 리플레이에서 GPU가 느렸던 사례

- 입력: 합성 관측 32,400행 × 16설정, 가상 매수 16회·매도 32회
- 결과: 기존 CPU 1.0423초, 공통 CPU 1.1267초, GPU 신호+CPU 체결 2.0350초
- 범위: 준비·GPU 초기화·전송·계산·동기화·파일 저장 포함
- 제한: 동시 작업이 있는 단회 측정. 실제 시장 성과 검증이 아님
- 판단: 이 규모에서 GPU 속도 이득이 없어 CPU 기본 유지
- 원문 위치: 개발 저장소 `docs/live-settings-replay.md`

## 증분 파일 확인

- 기록일: 2026-09-25
- 입력: 격리된 로컬 시험 파일 600개
- 결과: 최초 1.015초, 반복 확인 0.094초
- 반복 확인: 기존 유지 600개·복사 0개·전송 0바이트·오류 0개
- 제한: 같은 파일의 반복 확인이며, 원격 공유 폴더의 실제 전송 속도와 비교할 수 없음
- 원문 위치: 개발 저장소 `docs/incremental-transfer.md`

## 이번 공개 예제에서 재확인하는 범위

`python -m unittest discover -s tests -v`는 시간 차이 보정의 계산 항등식과 불일치 표본 거절을 검사합니다. 네트워크 시각 서버, 실제 계좌, 원본 시장 자료는 사용하지 않습니다.

## 아직 입증하지 못한 것

- 실제 주문의 대기열·부분 체결을 초봉으로 완전히 복원하는 능력
- 시장 전체 데이터의 무누락·무손실 수집
- 과거 탐색 결과가 미래 수익으로 이어지는지 여부
- 모든 입력 규모에서의 GPU 속도 우위
- 장시간 무중단 실거래 운용의 완성도
